**Bottom Line**
Schwab account opening from our app is possible, but it is not a normal public API we can just sign up for. It lives behind Schwab Advisor Services’ approved third-party integration program. The realistic near-term path is: generate Schwab-ready paperwork in Advisor Prep Hero, let the advisor review it, then hand it into Schwab’s own digital signing/onboarding flow. The full “click inside our app and send to Schwab” path needs Schwab approval.
**Schwab Programs**
- **Schwab Advisor Center**: Schwab’s main advisor portal. Its digital onboarding lets advisors open, set up, and fund multiple household accounts with one client email. It can auto-fill from Schwab and third-party platforms. ([advisorservices.schwab.com](https://advisorservices.schwab.com/serving-your-clients/acct-mgmnt-trading/account-management/digital-client-onboarding))
- **Digital Client Onboarding / DAO**: Schwab’s account-opening workflow. It supports individual, joint, Roth, rollover IRA, living trust, inherited IRA, custodial, and other common account types. Schwab says partners can pass up to 50 data points into onboarding. ([pressroom.aboutschwab.com](https://pressroom.aboutschwab.com/press-releases/press-release/2022/With-New-Digital-Onboarding-Enhancements-Schwab-Advisor-Services-Makes-it-Easier-to-Open-Multiple-Client-Accounts-for-Households/default.aspx))
- **eAuthorization**: Client approval inside Schwab/Schwab Alliance, used after the account-opening workflow is prepared. ([advisorservices.schwab.com](https://advisorservices.schwab.com/serving-your-clients/acct-mgmnt-trading/account-management/digital-client-onboarding))
- **DocuSign through Schwab Advisor Center**: Schwab-supported signing for eligible forms. Schwab’s older FAQ says forms signed outside Schwab’s DocuSign tool are not accepted, but a later “Advisor’s Own DocuSign” program allows approved firms to use their own DocuSign instance for listed Schwab forms. ([content.schwab.com](https://content.schwab.com/clientexperience/pdf/CS-4486_CET_FAQ_Forms_v2.pdf?utm_source=openai)) ([precisefp.com](https://precisefp.com/wp-content/uploads/2020/07/Advisors-Own-DocuSign-Eligible-Forms.pdf?utm_source=openai))
- **Schwab OpenView Gateway / Third-Party Integration**: The partner/API layer, provided by Performance Technologies, Inc. API integration, SSO, daily data files, and trading integration are separated across PTI and Schwab entities. ([schwab.com](https://www.schwab.com/resource/custodial-ira-application))
- **Post-TD Ameritrade**: TD Ameritrade clients are now Schwab clients; Schwab also says it added/deepened integrations so former Veo One users kept needed functionality. ([schwab.com](https://www.schwab.com/welcome-to-schwab)) 
**Partner Requirements**
Public Schwab pages do not publish a clean checklist like “SOC 2 required, cost is X, timeline is Y.” What is public: a vendor serving RIAs must contact Schwab through the “Work With Us” form, then Schwab’s team decides next steps. ([advisorservices.schwab.com](https://advisorservices.schwab.com/managing-your-business/tech-integration/lead-form))
The likely real checklist is: vendor review, legal agreements, security review, API testing, pilot, then production. Schwab describes dedicated team support, quality/security expectations, product managers, third-party relationship managers, integration specialists, and contract managers. ([schwab.com](https://www.schwab.com/resource/custodial-ira-application)) ([pressroom.aboutschwab.com](https://pressroom.aboutschwab.com/press-releases/press-release/2021/Schwab-Advisor-Services-Hosts-Second-Technology-Forum-for-Third-Party-Technology-Providers-Serving-Independent-Advisors/default.aspx))
For security, assume Schwab and RIAs will expect a serious vendor packet: SOC 2 Type II or active SOC 2 path, recent penetration test, encryption, access controls, audit logs, data-retention policy, incident plan, and breach notice process. This is partly market reality, not a public Schwab requirement. SEC Reg S-P now pushes advisors to oversee service providers handling customer data. ([federalregister.gov](https://www.federalregister.gov/documents/2024/06/03/2024-11116/regulation-s-p-privacy-of-consumer-financial-information-and-safeguarding-customer-information?utm_source=openai)) Jump, a direct competitor, publicly says it uses SOC 2 Type II, third-party penetration testing, encryption, MFA, and monitoring. ([help.jumpapp.com](https://help.jumpapp.com/en/articles/10055503-jump-security-and-data-privacy-faqs?utm_source=openai))
**What Actually Opens The Account**
The real account-opening action is Schwab’s Digital Onboarding flow, not our app becoming the custodian. A partner can prefill and initiate the workflow, then Schwab validates it and sends it to the client for eAuthorization. Advyzon’s public announcement says its Schwab Digital Onboarding API integration passes prepared account openings to Schwab Advisor Center for validation, client review, and eAuthorization. 
Known prefill fields include at least: full name, primary email, primary phone, date of birth, primary address, country of citizenship, and employment info. AdvisorEngine documents those fields for its Schwab OpenView Gateway digital account-opening flow.  Schwab’s own 2022 release says partners can pass up to 50 data points, but the full field list appears gated. ([pressroom.aboutschwab.com](https://pressroom.aboutschwab.com/press-releases/press-release/2022/With-New-Digital-Onboarding-Enhancements-Schwab-Advisor-Services-Makes-it-Easier-to-Open-Multiple-Client-Accounts-for-Households/default.aspx))

**Jump’s Approach**

**What We’d Do, In Order**
1. Build the no-partnership version first: Schwab field map, advisor review screen, PDF output, and “send through Schwab” instructions.
2. Build a compliance packet: SOC 2 path, pen test, data map, audit trail, encryption, retention, human review, incident response.
3. Get 1-3 Schwab-custody advisor firms willing to sponsor/pilot the workflow.
4. Submit Schwab’s “Work With Us” form as an RIA technology vendor.
5. Ask first for read/status access and SSO; ask separately for Digital Onboarding API access.
6. Pilot with one firm, then expand only after Schwab approves production use.
