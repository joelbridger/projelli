**Quick Wins**
- Build a generic **Export Inbox**: advisor drops PDFs/CSVs from RightCapital, eMoney, MoneyGuide, Nitrogen, Orion, Tamarac, Redtail, etc.; Advisor Prep Hero labels them clearly as snapshots.
- Reclassify Box, ShareFile, Jotform, DocuSign, Holistiplan, Salesforce, and Addepar as **BYO customer credentials**, not pure partnership blockers.
- Add Redtail “firm-only API key” path plus CSV fallback.
- Use ByAllAccounts/Akoya-style consent aggregation for custodians, especially Fidelity. Morningstar says ByAllAccounts supports wealth-focused aggregation, 1,200+ custodial sources, and direct-feed bundles. ([morningstar.com](https://www.morningstar.com/en-us/business/products/byallaccounts)) ([morningstar.com](https://www.morningstar.com/en-us/business/insights/blog/financial-data-aggregation))
**Needs Partnership / Long Game**
- Direct live custodian feeds: Fidelity, Pershing, Altruist, Schwab beyond existing workaround.
- Direct planning APIs: eMoney and MoneyGuide.
- Orion/Redtail/Black Diamond public marketplace-style integrations.
- Nitrogen Risk Engine API.
Recommended product change: stop selling most gated connectors as “blocked.” Sell three honest modes instead: **Live connection**, **Export folder**, and **Prepare-and-handoff**. That keeps the promise true while giving advisors value now.
