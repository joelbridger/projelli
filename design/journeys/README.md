# Journeys

This folder holds end-to-end advisor paths: for example first setup, a daily check-in, meeting preparation, meeting follow-up, or running a workflow. Each journey records the user’s steps, the purpose of each step, and the intended emotional arc — how the experience should feel along the way.

**Update trigger:** Update or add a journey when a new path is designed, when navigation changes, or when a coherence review finds that neighboring screens no longer make sense together.

**Naming:** `YYYY-MM-DD-journey-name.md` — for example, `2026-07-17-meeting-follow-up.md`.
