# Design Reviews

This folder holds the design-review verdicts for built work. Every verdict checks two things: **Craft** (whether the surface is well made) and **Coherence** (whether it belongs with the rest of Lantern). Link each verdict to its source spec and the screenshots reviewed.

**Update trigger:** Write a review at review time, before a UI-touching change is accepted. Refresh its screenshots at the same time. A finding that needs changes stays visible until a later verdict closes it.

**Naming:** `YYYY-MM-DD-surface-name-DESIGN-REVIEW.md` — for example, `2026-07-17-calendar-grid-DESIGN-REVIEW.md`.
