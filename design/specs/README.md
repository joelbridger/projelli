# Surface Specs

This folder holds the design source for a screen or changed part of a screen. A spec says what the surface is for, who uses it, its source in the prototype or system, required states, copy guidance, and the review checklist.

**Update trigger:** Create or update a spec at brief time, before a UI-touching feature is built or reviewed. If a surface is not covered by the prototype, label the spec as derived and flag whether Jameson’s blessing is needed.

**Naming:** `surface-name-SPEC.md` — for example, `booking-public-page-SPEC.md`.
