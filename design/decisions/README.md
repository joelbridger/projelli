# Design Decisions

This folder holds dated design rulings: Jameson’s blessings and rejections, accepted design changes, and important choices that change a journey, pattern, or visual direction. Each decision should state the context, the choice, why it was made, and what changes because of it.

**Update trigger:** Add a decision at blessing time or whenever a meaningful design direction is accepted, rejected, or redirected. Also append the lesson to `../JAMESON-TASTE.md` when it tells us something about Jameson’s taste.

**Naming:** `YYYY-MM-DD-short-decision-name.md` — for example, `2026-07-17-client-profile-card-grouping.md`.
