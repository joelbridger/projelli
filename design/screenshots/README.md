# Screenshots

This folder is the honest visual record of what the product looks like today. Keep one folder per surface and include the real states reviewed: normal, empty, loading, error, success, and meaningful variations.

**Update trigger:** Refresh screenshots at review time, whenever a design review is issued or accepted. Link them from the matching review verdict.

**Naming:** `surface-name/` for a surface folder; inside it use `YYYY-MM-DD-state-description.png` — for example, `calendar-grid/2026-07-17-empty-state.png`.
