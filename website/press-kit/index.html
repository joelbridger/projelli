Long-form (~340 words)

Keepance is the private intelligence layer for a law practice: a local-first desktop app where a firm's documents, email, and client matters live under the attorney's control, and where every question the attorney asks is answered with cited, verifiable sources. The architecture is designed around the constraint that professionals bound by confidentiality obligations face. There is no Keepance content server in the path between your machine and the AI provider. Your prompts go directly to the provider of your choice under your own API key, or through your firm's zero-retention proxy in Assured mode. With Ollama, nothing leaves your machine at all. Keepance never sees your work.

Word (.docx) is the primary format. The in-house OOXML engine handles tracked changes and AI redline natively, so attorneys work in the format courts and opposing counsel actually accept. Recall is matter-scoped with cryptographic isolation, so context from one client's files cannot bleed into another. The AI indexes documents and email across a matter and returns answers with citations you can verify. Scanned PDFs are handled via on-device OCR before indexing. An always-visible egress indicator, a printable Data Map, and a confidentiality spectrum (Local-only, BYOK-direct, Assured) make the trust story honest and inspectable.

The v3.0 release (June 2026) added the firm tier: SSO via OIDC so firms can provision seats through their existing identity provider; an encrypted workspace vault where sensitive files are stored as AES-256-GCM ciphertext with keys in the OS keychain; and live multi-user .docx co-editing where the relay only ever stores ciphertext and ethical walls are enforced by key denial, not UI hiding. OCR for scanned PDFs and email import with matter-scoped cited recall also shipped in this cycle. Profession workflow packs cover legal, tax, consulting, and advisor workflows.

Keepance is built by Jameson Daines, a Senior Product Designer at a health-tech company who built it on weekends and evenings. The technology stack is Tauri 2 (Rust + WebView), React 18 + TypeScript, Zustand for state management, an in-house OOXML engine for Word editing, LanceDB for the local vector store. Mac (signed + notarized), Windows (Azure-signed), Linux (.deb / .rpm / .AppImage) with auto-update. Pricing: $468/yr Solo ($39/mo annual) · $948/yr Professional (includes one profession pack; $79/mo annual) · $1,548/seat/yr Firm (minimum 3 seats; $129/mo annual). Sold via LemonSqueezy.

Recent releases

v3.2.0 (June 2026)

The v3.x cycle completed the full vision for law-practice private intelligence. Signed desktop builds (Windows, macOS, Linux) ship with auto-update.

  • SSO via OIDC: firm administrators provision seats through their existing identity provider. The Keepance desktop app verifies the ID token locally; no credentials pass through Keepance servers.
  • Encrypted workspace vault: sensitive files are stored as AES-256-GCM ciphertext with keys in the OS keychain. The vault is per-device and survives app updates without re-keying.
  • Live multi-user .docx co-editing: attorneys on the same matter can edit a Word document at the same time. The relay only ever stores and forwards ciphertext; ethical walls are enforced by key denial at the server, not UI hiding on the client.
  • OCR for scanned PDFs: on-device optical character recognition indexes scanned documents alongside native PDFs and Word files. No third-party OCR service; all processing stays on the attorney's machine.
  • Email import with matter-scoped cited recall: import an email thread and it joins the matter's index. The AI can answer questions across documents and email together, with citations back to the original message.
  • Word-native editing with tracked changes and AI redline: the in-house OOXML engine reads and writes real .docx files. Tracked changes are preserved across edit sessions; the AI proposes edits as redlines the attorney can accept or reject hunk by hunk.
  • Profession workflow packs: structured AI workflows for legal, tax, consulting, and advisor practices. Each pack ships with interview-driven templates that produce Word output.

v2.0 (May 2026)

Multimodal chat (images and PDFs inline), on-device PDF indexing via fastembed-rs + MultilingualE5Small stored in LanceDB, read-aloud via a local Piper sidecar, long-context compression, Spanish and German UI localization, and a browser demo at keepance.com/try.

v1.5 (April 2026)

Local RAG over your notes (@workspace). MCP server as a Desktop Extension for Claude Desktop, Cursor, and Zed. Side-by-side AI editing with streaming diffs and per-hunk accept / reject. Voice input. Ollama as a fourth provider.

v1.0 (March 2026, commercial launch)

Initial commercial release: Markdown editor with BYOK chat with Claude / GPT / Gemini, profession-specific workflow template packs, version history, Tauri desktop app for Mac (signed + notarized) and Windows (Azure-signed), subscription pricing via LemonSqueezy.
