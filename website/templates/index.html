Fifteen founder workflow templates ship with Projelli. Below is the real output from each one, filled in against a fictional freelancer finance app. Click any card to read the full document.

About the example company. Every sample below uses the same fictional founder (Maya, ex-Ramp PM) building the same fictional product (Acme Budget, a personal finance app for US freelancers with lumpy income). The documents were generated by running the real templates inside Projelli using Claude Sonnet 4.5 and lightly edited for brevity.
