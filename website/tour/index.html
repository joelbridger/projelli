More v2.0 features (videos coming)

Videos 2 and 3 above cover the browser demo and the plugin sandbox. Here's the rest of v2.0 that doesn't have a clip yet.

Images in chat

Paperclip, paste, or drag-drop an image into chat. Claude, GPT, Gemini, and Ollama vision models all handle it.

PDF chat + RAG

Drop a PDF into chat or toggle "Include PDFs in workspace index" so every PDF in your folder becomes searchable AI context.

Plugin marketplace

Settings, Marketplace, Plugins. Sandboxed Web Worker runtime, six-permission consent dialog, four day-one plugins.

Templates marketplace

Browse, install, update, and uninstall community templates from github.com/projelli/community-templates.

Read aloud

Click "Read aloud" on any AI message. Local Piper sidecar, no cloud.

Long-context Compress

Long chats now offer a one-click compress that batches earlier turns through a fast model. Expand or clear from the same control.

Spanish + German

Full UI translation. Auto-detects on first launch. Switch any time in Settings, General, Language.
