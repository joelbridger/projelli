Getting Started with Projelli

A 5-minute guide from download to your first AI-generated business document.

Projelli is a desktop app you install on your computer. It runs locally, your files never go to our servers, and your AI conversations go directly from your computer to whatever AI provider you choose. This guide walks you through installation, setup, and your first workflow.

Try it in your browser first

Want to kick the tires before downloading anything? The in-browser demo at projelli.com/try runs a real Projelli session against a pre-seeded sample workspace. No download, no API key, no signup. You can poke around for a few minutes and see what the editor + chat + workflows actually feel like.

Open the in-browser demo →

Step 1: Download and install

Windows

  1. Click Download for Windows and grab Projelli_x.y.z_x64-setup.exe
  2. Double-click the installer. There's no wizard, just a brief progress window. That's intentional. Projelli is signed via Azure Trusted Signing so SmartScreen will not warn you.
  3. Projelli launches automatically when install finishes, and you'll find a desktop shortcut for next time.
  4. Want the full installer wizard instead? Open a terminal and run Projelli_x.y.z_x64-setup.exe /INTERACTIVE

macOS

  1. Click Download for macOS. Pick Projelli_x.y.z_aarch64.dmg for Apple Silicon (M1/M2/M3/M4) or Projelli_x.y.z_x64.dmg for Intel Macs.
  2. Open the DMG and drag Projelli into Applications.
  3. The first time you launch, macOS will say "Apple cannot verify Projelli is free of malware." Projelli is signed with our Apple Developer ID, but Apple's notary service has been intermittently slow since spring 2026, so we're shipping signed-only for now. To open: right-click Projelli in Applications → Open → "Open Anyway". You only need to do this once.
  4. If the right-click flow doesn't work on your version of macOS, go to System Settings → Privacy & Security, scroll to the bottom, and click "Open Anyway" next to the Projelli entry.

Linux (coming after launch)

AppImage, .deb, and .rpm builds are produced by our CI and live on the releases page, but Linux is not officially supported in v1.6. We'll polish + announce Linux as a v1.7 release after the v1.6 launch settles.

Step 2: Create your first workspace

The first time you launch Projelli, it asks you to pick a workspace folder. This folder is where ALL your work will live, every document, every AI conversation, every file is just a regular file inside this folder.

Pick a folder that's easy to find and easy to back up. Common choices:

  • ~/Documents/Projelli on Mac
  • C:\Users\YourName\Documents\Projelli on Windows
  • A folder inside Dropbox, iCloud, or OneDrive, if you do this, you get automatic sync across devices for free, since Projelli writes plain Markdown files that any sync tool can handle

Click "Create Workspace" and choose your folder. Projelli will set up the folder structure (a few subdirectories for your files, audit log, and trash).

Step 3: Add an AI provider key

Projelli works with four AI providers: Anthropic Claude, OpenAI ChatGPT, Google Gemini, and Ollama (local, free, no key needed). You bring your own API key for one of the cloud providers, or you point Projelli at a local Ollama install. This is how Projelli stays local-first and private, your AI requests go directly from your computer to the provider, never through us.

If you don't have a key yet and just want to test, the in-browser demo at projelli.com/try works without one. Worth trying before you sign up for an API account.

You only need ONE provider to get started. Most people use Claude (Anthropic) because it's the best at long-form writing and follows instructions well. But all four work.

To get an API key, see our API Keys Guide. The short version:

  • Claude: console.anthropic.com → API Keys → "Create Key"
  • OpenAI: platform.openai.com/api-keys
  • Google: aistudio.google.com/app/apikey

Once you have a key, in Projelli go to Settings → API Keys and paste it in. Keys are stored in your operating system's secure keychain, Keychain on Mac, Credential Manager on Windows, Secret Service on Linux. They're never written to a file or sent to us.

Step 4: Run your first workflow

Now the magic. Click the Workflows button in the sidebar. You'll see a list of templates, start with "New Business Kickoff".

The workflow asks you a series of questions about your business idea (the problem, the customer, the unique angle, the go-to-market). Answer them with whatever level of detail you have, even rough ideas work.

When you click "Generate," Projelli sends your answers to your chosen AI provider and produces a set of real, editable Markdown files in your workspace:

  • VISION.md, your business vision
  • PROBLEM.md, the problem statement
  • CUSTOMER.md, your target customer profile
  • STRATEGY.md, go-to-market strategy
  • NEXT-STEPS.md, concrete actions

These are real files. You can open them in Projelli's editor, edit them inline, link them together with [[wiki-style links]], and back them up however you want.

Step 5: Iterate

This is where it gets interesting. Open one of the generated files. Use the AI chat panel on the right to ask for changes: "rewrite this paragraph more concisely," "add a section about pricing," "what am I missing about competitors?" Each AI response either updates the existing file or creates a new linked file.

Every change is versioned. You can undo, see diffs, and recover deleted files from the trash. Every AI action is logged in the audit log so you have a complete record of what was generated, when, and from which prompt.

What's next

You're set up. From here:

  • Try other workflow templates: Competitor Analysis, Pitch Deck, Landing Page Copy, MVP Scope, Pricing Strategy, and more
  • Use wiki-links ([[document-name]]) to connect your documents into a knowledge graph
  • Use the source cards feature to track research with citations
  • Use the whiteboard for visual brainstorming
  • Use the audio recorder for capturing voice memos that the AI can transcribe

What you can do in v2.0

The v2.0 release shipped a bunch of new things on top of the core editor + chat + workflows. Worth a look once you have the basics working:

  • Marketplace. Open Settings → Marketplace to browse and install community templates and plugins. Six community templates and four plugins shipped on day one.
  • Image and PDF chat. Drag an image or a PDF into the chat input. Claude gets native PDF; other providers get text-extracted via PDF.js. Same paperclip-and-paste pattern works for screenshots.
  • Read aloud. Click "Read aloud" on any AI message. Runs locally via the Piper sidecar, no cloud round trip.
  • Spanish or German UI. Settings → General → Language. The whole app, all 421 strings, available in Español and Deutsch alongside English.
  • The full v2.0 picture. The v2.0 announce post walks through every shipped feature with screenshots.
