WHAT PROJELLI DOES

Four capabilities, one local-first app

Every feature below runs on your machine with your own API keys. Nothing you type is ever sent to a Keepance server.

Memory that indexes your work

The AI workspace that remembers your stuff. A local vector index (LanceDB + e5-small) over every Markdown file you've written, plus a memory.json facts file extracted from your chats. Ask "what did I say about pricing?" and the answer comes back with citations.

Read why chat shouldn't evaporate →

Available in every AI tool you use

Your workspace, everywhere. Keepance ships a Model Context Protocol server as a one-click .mcpb bundle. Install it in Claude Desktop, Cursor, or Zed and those clients can read, search, and (with approval) write your Keepance workspace.

Learn about MCP →

AI edits side-by-side with you

The Canvas pattern, but local. Select any paragraph, ask "tighten this," watch a streaming diff land in place. Per-hunk Accept or Reject, or accept-all. Every AI edit gets logged to version history with the prompt + model + offset range, so you can always see what the AI changed.

HOW IT WORKS

Three steps to get a project out of your head

No setup, no tutorial. Open the app, pick a template, start typing.

1

Pick a template

Start from one of the 15 founder templates or a blank project. Each template already knows the documents you probably need and helps you fill them in.

2

Talk to the AI

Describe the project in your own words. The AI asks a few follow-up questions, then drafts the documents you would have written yourself if you had two extra hours.

3

Edit and link

Fix up the drafts in the Markdown editor, link related notes with wiki-links, and keep iterating until the whole project sits in one place you trust.
