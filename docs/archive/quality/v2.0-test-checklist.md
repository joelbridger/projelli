# Advisor Prep Hero v2.0 Test Checklist

_For Jameson's pre-launch smoke test on Windows + macOS. Walk this top-to-bottom on each platform. Mark Pass / Fail / Note per row._

## Setup

- **Where to download:** GitHub Releases page at `https://github.com/keepance/keepance/releases` (the v2.0.0 build artifacts appear once the release workflow completes the matrix build, ~25-40 minutes after tag push).
- **Mac assets:** `Advisor Prep Hero_2.0.0_aarch64.dmg` (Apple Silicon) and `Advisor Prep Hero_2.0.0_x64.dmg` (Intel). Apple-signed and notarized.
- **Windows asset:** `Advisor Prep Hero_2.0.0_x64-setup.exe`. Azure Trusted Signing.
- **Linux assets:** `.AppImage`, `.deb`, `.rpm`. Unofficial.
- **Test workspace:** create a fresh folder named `~/Advisor Prep Hero-v2-test/` so installs don't collide with your daily workspace. Copy 2 sample PDFs and 2 sample images into it ahead of time so the multimodal tests have real content to use.
- **Test API keys:** have at least Anthropic + OpenAI set up. Optional Gemini + Ollama if you want to test all four providers.

## Cross-platform regression baseline

These should all still work from v1.7.2. If any of them broke, that's a v2.0 regression and a release blocker.

- [ ] App launches without errors (no red toast on startup, no console error spam)
- [ ] License activation OR 30-day trial banner appears correctly
- [ ] Workspace selector picks a folder; folder loads
- [ ] File tree shows files; tab opens; markdown editor renders
- [ ] Wiki-link `[[note]]` resolves; backlinks panel shows reverse refs
- [ ] Chat starts, sends a text message, streams a response from Claude
- [ ] OS keychain stores the API key (close + reopen app, key still works)
- [ ] Settings page opens; theme toggle works
- [ ] Audit log shows recent events
- [ ] Auto-updater check runs on launch (Help → Check for Updates if not auto)
- [ ] MCP server still works (if you have an MCP client to point at it)
- [ ] Voice input (Parakeet) still records + transcribes
- [ ] Existing 15 founder workflow templates still launch + complete

## Stream A: Multimodal images, PDF chat, PDF RAG, long context

### Image attachments
- [ ] **Paperclip → image:** click the paperclip in chat input, pick a PNG/JPG, the thumbnail appears as a pending attachment
- [ ] **Paste image:** copy an image to clipboard, paste into chat input, attaches
- [ ] **Drag-drop image:** drag a file from Finder/Explorer onto the chat input, attaches
- [ ] **Send to Claude (Sonnet 4.6 or Opus):** AI describes the image content correctly
- [ ] **Send to OpenAI (GPT-4 / GPT-4o):** same, AI describes correctly
- [ ] **Send to Gemini (gemini-1.5-pro or 2.0):** same
- [ ] **Send to Ollama (a vision-capable model like llava):** same
- [ ] **Vision-warning:** if you have a non-vision model selected (e.g., GPT-3.5 or text-only Ollama model), a warning appears above send button + offers a model swap
- [ ] **Cost meter** updates with image-token estimate; visible somewhere in the chat UI
- [ ] **Persistence:** close + reopen the chat file; image attachment is still rendered in the conversation history
- [ ] **Audit log:** `attachment_added` and `attachment_sent_to_provider` events appear

### PDF chat
- [ ] **Drag-drop PDF:** drag a PDF onto chat input; attaches as a PDF, NOT extracted to images
- [ ] **Send to Claude Sonnet/Opus:** sends as **native PDF** (mode chip says "native PDF"); AI summarizes correctly
- [ ] **Send to OpenAI:** mode chip says "text extracted"; AI summarizes from extracted text
- [ ] **Send to Gemini:** same as OpenAI
- [ ] **Send to Ollama:** same as OpenAI
- [ ] **Mode chip is visible** in the message bubble (not buried)
- [ ] **Multi-page PDF:** drop a 5+ page PDF, AI references later pages correctly

### PDF RAG (workspace index)
- [ ] **Settings → Memory → "Include PDFs in workspace index":** toggle ON
- [ ] **Drop a PDF into your workspace folder** (in the file tree, not chat)
- [ ] Wait for indexing toast / status indicator (LanceDB embeds in background)
- [ ] In chat, ask a question that's only answerable from the PDF content
- [ ] **AI cites the PDF** (or at minimum returns content from it, not a fabrication)
- [ ] **Toggle OFF + retest:** AI no longer references the PDF
- [ ] **Vectors stored at:** `<workspace>/.keepance/vectors/` (verify folder exists)

### Long context [Compress]
- [ ] **Open or create a long chat** (~50+ messages or one near the model's context window). Easiest: paste a 5000-word doc into chat.
- [ ] **[Compress] button appears** at the top of the chat or in a banner
- [ ] **Click [Compress]:** modal opens with summary preview
- [ ] **Confirm:** chat compresses; previous messages shown as "Compressed" entry
- [ ] **Continue chatting:** AI responds with compressed context maintained
- [ ] **Expand compressed entry:** original messages still readable
- [ ] **Auto-trigger:** at some context threshold (set in Settings), the compress modal auto-opens

## Cross-platform parity checks (Mac vs Windows)

These should behave identically on both platforms. If a feature works on Mac but breaks on Windows (or vice versa), that's a release blocker.

- [ ] Image paste (Cmd+V on Mac, Ctrl+V on Windows)
- [ ] PDF drag-drop (path resolution differs by OS)
- [ ] Read aloud (Piper binary architecture differs; Mac has aarch64 + x86_64 builds, Windows has x64)
- [ ] Plugin install + worker spawn (Web Workers should work in Tauri 2 webview on both)
- [ ] Tarball extract (Tauri command goes through Rust; should be identical)
- [ ] OS keychain (macOS Keychain vs Windows Credential Manager — Tauri abstracts both)
- [ ] Workspace folder picker (native dialog differs in look but should work)
- [ ] Auto-updater (Mac uses appcast XML, Windows uses Azure update mechanism — both should detect new releases)

## Performance / polish (subjective)

- [ ] **Cold start:** under 3 seconds on both platforms (acceptable threshold)
- [ ] **First image attachment:** preview generates within 1 second
- [ ] **First plugin install:** end-to-end (download → consent → enable → first invoke) under 30 seconds with a normal connection
- [ ] **Read aloud first run:** Piper download + first speech under 60 seconds; subsequent reads under 5 seconds startup
- [ ] **Memory after 30 minutes of use:** RAM usage isn't growing unboundedly. Open Activity Monitor / Task Manager and check.
