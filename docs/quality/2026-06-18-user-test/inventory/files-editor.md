# Files + Document Editor + Trash/Versions

Domain covers: file tree (create/rename/move/delete/drag-drop/multi-select), all editor surfaces (.docx OOXML engine via DocxEditor, CodeMirror plain-text for .md/.txt/.json), tab bar, split pane, autosave indicator, version history (text localStorage + binary disk snapshots), Trash (soft delete / restore / permanent delete / retention), and first-edit binary backup.

Sources: `src/features/documents/`, `src/platform/history/TrashService.ts`, `src/platform/history/HistoryService.ts`, `src/features/documents/versioning/`, `src/platform/fs/fileBackupStore.ts`.
