## Coverage Gaps And Recommended Changes

- `AssociateHome.tsx` uses `LAW_FEATURED_ID = 'deposition-contradiction-finder'`, but the real registry id is `legal-deposition-contradiction-finder`. The "Start here" highlight likely never appears in production. Add a test using the real `allWorkflows` registry, not mocked old ids.
- No archive action exists for matters, although the requested domain includes rename/archive. Current UI supports rename and delete/unlink only. Add an archive flag and an archived filter/recovery path, or explicitly remove "archive" from acceptance scope.
- Most non-legal workflow templates have metadata/verification coverage only, not runtime coverage. Add a parameterized smoke test that executes every template with minimal interview answers using `MockProvider` and asserts expected artifact filenames.
- `RunRecordService` has no direct unit coverage for query, diff, stats, JSON export/import, or clear. Add focused service tests because run history is an audit surface.
- `InterviewForm` required-field validation and workflow cancel persistence are not directly covered. Add component tests for required validation and an execution-tab cancellation test that verifies the persisted `.workflow` status.
- Folder and email mapping UI paths in `MatterManagerDialog` are covered at store/resolver level, but not by UI tests. Add RTL tests for `matter-folder-*` and `matter-mail-*` toggles.
- `.docx` and `.pptx` export are correctly classified as L2. Browser tests can assert buttons and mocked bytes, but a release gate should include a real Tauri/native export pass that opens the produced Office files.
