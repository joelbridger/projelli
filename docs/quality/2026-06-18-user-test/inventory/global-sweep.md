# Global App-Shell Sweep

Domain covers every remaining interactive surface not owned cleanly by onboarding, files/editor, chat/search, email, workflows/matters, firm, or privacy/settings/keys: app shell, surface navigation, global bars, shell dialogs, toasts, empty/loading/error states, drag-and-drop, media/dictation shell pieces, native window behavior, and reusable UI primitives. Overlaps are included when ownership is ambiguous.
