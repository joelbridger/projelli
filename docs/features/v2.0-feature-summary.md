# Advisor Prep Hero v2.0 Feature Summary

_Captured 2026-05-04 after the v2.0 mega-release shipped to master._

This is the canonical user-facing feature inventory for v2.0. Every row maps to a merged PR and a stream from `docs/superpowers/specs/2026-04-28-v2.0-mega-release-design.md`.

## Features shipped

| Feature | Surface | PR / Stream |
|---|---|---|
| **Image attachments** to AI chat | Paperclip + paste + drag-drop on chat input. Per-provider format (Claude / OpenAI / Gemini / Ollama / Mock). Vision-model warning + token cost meter. | #20 Stream A |
| **PDF chat** | Drop a PDF into chat. Claude / Opus get native PDF; others get text-extracted via PDF.js with a "text extracted" mode chip. | #20 Stream A |
| **PDF RAG** | "Include PDFs in workspace index" toggle in Settings -> Memory. PDFs become searchable context for chat. LanceDB + fastembed-rs MultilingualE5Small (384-dim). | #20 Stream A |
| **Long-context [Compress]** | Auto-trigger modal + manual button on long chats. Batched compression via fast-model routing, expand / clear, audit event. | #20 Stream A |
| **Read Aloud (TTS)** | Click "Read aloud" on any AI message. Local Piper sidecar binary, no cloud. | #19 Stream B |
| **Templates marketplace** | Settings -> Marketplace -> Templates. Browse, install, update, uninstall community workflow templates. Catalog at `github.com/keepance/community-templates` (6 day-one entries; GitHub Action auto-rebuilds catalog.json on PR merge). 24-hour cached + offline banner. Provenance badges in WorkflowPanel. Update count nav badge. | #21 Stream C1 + #26 Stream C6 |
| **Plugin system** | Sandboxed Web Worker runtime, manifest-declared permission model (6 permissions: workspace:read / write, editor:selection / write, ai:invoke, network), full PluginAPI (commands / toolbar / sidebar / editor / workspace / ai / storage / network / settings / notify). Plugin contributions appear in toolbar, sidebar, command palette, settings. Crash isolation with [Restart] UI. | #23 Stream C3 |
| **Plugin marketplace** | Settings -> Marketplace -> Plugins. Permission-consent dialog before install (plain-language risk labels). Installed list with status (enabled / disabled / crashed) + per-status actions. Catalog at `github.com/keepance/community-plugins` (4 day-one plugins). | #24 Stream C4 + #26 Stream C6 |
| **4 example plugins** | Word Counter (live word count sidebar), Translator (AI-powered selection translation), Pomodoro (timer with notify + storage), Mermaid Preview (renders mermaid blocks via CDN-loaded library). All live in the plugin marketplace. | #25 Stream C5 + #26 Stream C6 |
| **Plugin developer ecosystem** | `npx create-keepance-plugin <name>` scaffolder, `@keepance/plugin-api` types package, 7 docs pages at `keepance.com/docs/plugins/` (getting-started, manifest reference, permissions, API reference, publishing, examples, hub). ESM bundle target via Vite. | #25 Stream C5 |
| **Mobile access docs** | New `keepance.com/docs/mobile-access/` with iCloud Drive / Dropbox / Syncthing / Google Drive setup pages. In-app Settings -> Mobile mirror with the same content + iOS deep links. | #22 Stream D1 |
| **Web demo at keepance.com/try** | Pre-seeded sample workspace, 5-message OR 10-minute demo limit via shared Anthropic-key Bun proxy, BYOK input for unlimited use, exit modal with download CTAs, Plausible-instrumented events, UTM-tagged downloads. Caddy + systemd live. | #27 Stream D-web |
| **Spanish + German localization** | 421 UI keys translated by `claude-sonnet-4-6` for ~$0.65 (idempotent re-run via `npm run translate-i18n`). Settings -> General -> Language picker (English / Espanol / Deutsch). OS locale auto-detect on first launch (Tauri `os.locale()` with `navigator.language` web fallback). ESLint rule `keepance-i18n/no-hardcoded-string` blocks new hardcoded strings in CI. Lock mechanism (`__locked: true`) preserves human-edited strings on re-translation. | #28 Stream E |
| **Cross-cutting foundations** | Sidecar trait abstraction (Parakeet voice + Piper TTS share lifecycle / IPC / error handling), MarketplaceService skeleton (used by templates AND plugins), ChatAttachment type system, audit event extensions for plugin / template / language events, Settings nav placeholders for the 4 new pages. | #18 foundations |

## Deliberate non-goals (NOT in scope per spec section 1.2)

| Non-goal | Why excluded |
|---|---|
| Cloud sync built-in | Local-first is the differentiator; cloud sync would invert the value prop. |
| Real-time collaboration | Adds server infrastructure + shifts product positioning. |
| Agentic / autonomous AI workflows | "AI proposes, user decides" is a stated principle. |
| Mass-market subscription tier | One-time pricing is the moat. |
| Vertical SKUs (legal / medical / academic) | Premature; revisit post-v2.0 if buyer signal demands. |

| 4.5 Long context > 200K tokens | MEDIUM | Shipped via #20 (long-context UX with [Compress]) |

| 4.7 Plugin system / extensions marketplace | LOW | Shipped via #23 + #24 + #25 + #26 |

**Result: 8 of 9 gaps fully addressed in v2.0. The remaining gap (4.3 Mobile) is partially addressed via D1 docs; the dedicated mobile reader is a follow-up release blocked on hardware + Apple Developer signup, not on Advisor Prep Hero engineering capacity.**
