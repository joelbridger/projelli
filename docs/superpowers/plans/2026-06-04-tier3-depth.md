## Task T3-4: Real PowerPoint deck export for consulting

**Goal:** Replace the current flat-text-to-slide PPTX export with a structured deck that carries speaker notes, renders tables as tables, applies a clean theme, and generates from the Slide Outliner's structured output rather than re-parsing flat Markdown.

**Files:**
- Modify: `src/utils/pptx-io.ts` (core export function)
- Modify: `src/modules/workflow/templates/consulting/NdaSafeSlideOutliner.ts` (output format — add explicit per-slide JSON schema)
- Add: `tests/unit/pptx-export.test.ts`

**Architecture:** The Slide Outliner template currently generates Markdown with headings as slides and bullets as content. The improvement: add a `slideSchema` field to the template config that tells the exporter to parse structured JSON from the AI output instead of Markdown. The exporter then builds PptxGenJS slides from that JSON, preserving: title, content bullets, speaker-notes, and any 2-column layouts or 2x2 matrices.

- [ ] **Step 1: Define the slide JSON schema**

```typescript
// In NdaSafeSlideOutliner.ts, add to the template config:
slideSchema: {
  type: 'array',
  items: {
    title: 'string',
    layout: 'title-only | bullets | two-column | 2x2',
    bullets: 'string[]',
    speakerNotes: 'string',
    tableData: '{ headers: string[], rows: string[][] } | null',
  }
}
```

Update the template prompt to output JSON matching this schema (inside a ```json code fence) in addition to or instead of Markdown.

- [ ] **Step 2: Write the failing test**

```typescript

    const slides = [
      { title: 'Market Opportunity', layout: 'bullets' as const,
        bullets: ['$2B TAM', '15% CAGR', 'Fragmented incumbent landscape'],
        speakerNotes: 'Emphasize the TAM is conservative.', tableData: null },
    ];
    const buffer = await buildPptxFromSlideJSON(slides, { firmName: 'Acme Consulting' });
    expect(buffer).toBeInstanceOf(Uint8Array);
    expect(buffer.length).toBeGreaterThan(1000);
  });

  it('renders a table slide correctly', async () => {
    const slides = [
      { title: 'Competitive Landscape', layout: 'two-column' as const,
        bullets: [], speakerNotes: '',
        tableData: { headers: ['Competitor', 'Strength', 'Weakness'],
                     rows: [['Acme Corp', 'Brand', 'Price'], ['Beta LLC', 'Price', 'Support']] } },
    ];
    const buffer = await buildPptxFromSlideJSON(slides, {});
    expect(buffer).toBeInstanceOf(Uint8Array);
    expect(buffer.length).toBeGreaterThan(1000);
  });
});
```
