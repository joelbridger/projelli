Notes for Jameson

  1. The strip is an offer, not a demand. It sits at the top of your normal home, it can be hidden for the day, and when there are no meetings it simply is not there. Try the “No meetings” state: the home looks completely untouched.
  2. Unmatched meetings never file themselves. A meeting we cannot confidently match is greyed out and asks “Whose meeting is this?” You decide. Assigning it once teaches the app, so the confirmation says the next “Acme Planning sync” will file itself.
  3. Clicking a matched meeting just focuses that client. No new screen, no popup. It is the same as clicking the client’s row, so the strip is a shortcut into the app you already have, not a new place to learn.
