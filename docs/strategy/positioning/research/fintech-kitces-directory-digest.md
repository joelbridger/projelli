# Digest — fintech.kitces.com (Kitces AdvisorTech Directory)

**Source:** https://fintech.kitces.com — the interactive web companion to the Kitces AdvisorTech Solutions Map. Rendered via the live Chrome browser (the site is a JavaScript app; plain fetch returns only a placeholder).
**What this is:** A browsable/searchable directory of advisor software, organized by the same taxonomy as the Map, plus a "Stack Builder" and curated "sample stacks." Its underlying ratings/adoption data is the same dataset summarized in `kitces-report-2025-digest.md`, so this digest captures the *structure and the sample-stack resource* rather than re-listing every tool.

## Site structure
- **Browse Categories (6 super-areas):** Operations Essentials · Financial Planning · Business Development · Investment Management · Client Engagement · Advisor Platform ("all-in-one" hubs).
- **Popular Categories:** CRM, Financial Planning, Portfolio Management, Document Management, Custodial Platform, Website, Client Data Gathering, Client File Sharing, Client Portal, Compliance, E-Signature, Investment Data/Analytics.
- **Stack Builder:** lets an advisor assemble + save a tech stack (https://fintech.kitces.com/build-my-stack).
- **Sample Stacks (curated reference stacks by firm type):** XYPN Tech Stack · Startup Advisor · **Solopreneur** · Mid-Sized Firm · Ensemble Firm. These are the best quick reference for "what a real stack of a given firm size actually contains" — useful when validating Keepance's demo stack and ICP.

## How to use it for Keepance
- It is the **canonical, advisor-trusted place advisors go to discover and compare tools** — i.e., part of the peer/research-led procurement path the Kitces report describes (vendor demos 49%, peers 43%, blogs/podcasts 33%, studies 31%). Being listed/visible here (and on the Map) is a credible distribution touchpoint for an advisor tool.
- The **Solopreneur / Startup / XYPN sample stacks** are the most relevant to Keepance's ICP (solo & small RIAs); browse them interactively to confirm the exact tools to mirror in the demo workspace (they will closely match the stack already documented: Wealthbox, RightCapital, Holistiplan, a custodian, Microsoft 365/OneDrive, an AI notetaker).
- **No category exists for "a private layer that reads across everything."** The closest existing shelves are "Client Engagement → AI Assistant" and "Advisor Platform" (all-in-one hubs) — neither of which is the right home for Keepance, reinforcing the positioning conclusion that Keepance is a cross-category layer, not a new box.

> Note: the per-tool detail pages and ratings on this directory duplicate the survey data already captured in `kitces-report-2025-digest.md`. For specific tool ratings, use that digest or browse the live directory.
