# Advisor Prep Hero Proof Sprint — June 2026

**Status:** Active. This is the operating plan for the next ~2 months.
**Owner:** Jameson.
**Decision date:** 2026-06-25.

---

## The committed direction (in one paragraph)

Advisor Prep Hero is an impressive, deep product with almost no customers yet. The building is far ahead of the selling (0 paying customers, ~225 site visitors in 10 weeks, ~5 "Buy" clicks). So for roughly the next two months we are **not** adding big new features. Instead we are running a focused **proof sprint**: use the demo to turn a handful of real financial advisors into *weekly* users, with at least 1–2 paying. The first user is Jameson's wife (a financial advisor); next is her firm; next is a few advisors from advisor communities. The advisor direction counts as validated only if **3–5 advisors are using Advisor Prep Hero every week within ~45–60 days, with some paying.** This was decided after a full CEO-level evaluation (see the report linked below) in which an independent Claude research pass and an independent Codex review reached the same verdict.

**The scoreboard for the next 60 days:** advisors using it weekly, and paid pilots. Not features, not downloads, not compliments.

Full evaluation report (private): https://jameworld.com/claudereports/r/2026-06-24-keepance-full-evaluation-and-where-to-go-next-june-2026.html

## The three first moves (and who owns them)

1. **Finish + sanitize the demo, then run the "first 5 advisors" sprint.** (Demo build: dedicated instance. Sprint: Jameson, using doc 01.)
2. **Make ONE path bulletproof** — pick client folder → build Client Map → ask a cited question → draft a review note. Pause all other big feature work. (Engineering.)
3. **Build the trust packet** — form a real business entity (Jameson), the data-flow sheet (doc 03), and scrub any wording that sounds like a compliance guarantee.

## What this sprint deliberately is NOT

- Not a feature-building cycle.
- Not a broad public launch.
- Not chasing enterprise firms or custodian integrations yet.
- Not counting downloads or compliments as progress.
